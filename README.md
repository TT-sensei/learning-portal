# TT-sensei 学びのポータル｜子どもと先生の学びの入口

TT-senseiが作成した小学校向けの学習サイト、教室ツール、教材制作素材を、子ども向け・先生向けに分けて案内するポータルです。

## 公開ページ

[GitHub Pagesで公開しています](https://tt-sensei.github.io/learning-portal/)。

- 子ども向け／先生向けの切り替え
- 子ども向けは学習教材だけを教科別に表示
- 先生向けは教材、教室ツール、共通基盤、NAVI CHARACTER素材サイトを表示
- サイト名、内容、リポジトリ名で検索
- 国語、算数、理科、社会、家庭科、英語などの教科フィルター
- 公開サイトとGitHubリポジトリへの導線
- 前回の検索・絞り込み条件を端末内に保存

## 主な掲載内容

### 子ども向けの学習サイト

- こそあど！：場面を見て、これ・それ・あれ・どれなどの指示語を考える
- ことのは ― 敬語のたしなみ ―：5〜6年生向けの敬語学習
- 漢字マスター書取り練習：漢字の書き取り練習
- 漢字読みファンタジー：漢字の読み学習
- 割り算ファンタジーバトル：割り算をファンタジーとバトルで練習
- 割り算筆算バトル：割り算の筆算をバトルで練習
- 数のしくみ：2・3年生向けの数の学習
- 理科ラボ、九九ファンタジーバトル、百マス計算など

### 先生向けの素材・基盤

- NAVI CHARACTER：6人の通常版、日常・学習シーン、ファンタジーキャラクター、背景、モンスター素材
- edu-kit：教材制作の設計ハブとAI向けガイド
- edu-components：出題、判定、得点、保存、進捗などのロジック部品
- edu-effects：教材UI、正誤、達成、バッジなどの演出
- sounds-recipe-：教材向けサウンドレシピ
- edu-assets：バッジ、エレメント、コレクション画像

## 表示モード

- 子ども向け：学習サイトだけを表示し、教科から選びやすい構成です。6人のナビキャラと明るい配色で学習の入口をつくります。
- 先生向け：教材、教室ツール、共通素材をまとめて表示します。NAVI CHARACTER素材サイトと各共通基盤には、サイトとGitHubの両方から移動できます。

表示モードと検索・絞り込み条件は端末内に保存します。学習記録そのものは各教材のlocalStorageで管理し、ポータル側では教材を探す入口に集中しています。

## 開発

HTML / CSS / JavaScriptのみで構成しています。UIの基本部品はedu-effects、絞り込み条件の保存はedu-componentsのStorageManagerを利用しています。

正しい漢字小テスト（kanji_syotest）は掲載していません。
