# TT-sensei 学びのポータル

TT-senseiが作成した小学校向けの学習サイト・学習ツール・素材をまとめるポータルサイトです。

## 公開ページ

GitHub Pagesで公開します。

- 教材・ツール・素材のカテゴリ分け
- 国語・算数・理科・社会などの教科フィルター
- サイト名・内容の検索
- 各教材へのリンク

漢字小テスト（kanji_syotest）は掲載していません。

## デザイン

[デジタル庁デザインシステム](https://design.digital.go.jp/)を参考に、情報の見つけやすさ、読みやすさ、コントラスト、キーボード操作時のフォーカス表示を意識しています。

## 開発

HTML / CSS / JavaScriptのみで構成しています。
